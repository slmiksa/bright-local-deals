

# خطة إنشاء مستند شامل لتطبيق لمحة للتسويق

سأنشئ ملف نصي (Markdown) شامل يحتوي على كل تفاصيل التطبيق من الألف إلى الياء ليتم تسليمه لمبرمج Flutter.

## محتويات المستند

### القسم 1: بيانات الاتصال بقاعدة البيانات
- Supabase URL, Anon Key, Project Ref
- كود التهيئة في Flutter

### القسم 2: هيكل قاعدة البيانات الكامل (19 جدول)
كل جدول مع أعمدته وأنواعها وعلاقاته وسياسات RLS

### القسم 3: Storage Buckets
قائمة الـ 5 buckets المتاحة وطريقة الوصول

### القسم 4: هيكل الشاشات والصفحات
- **الصفحة الرئيسية**: العد التنازلي → سلايدر البانر → السحوبات → المميزة → الفعاليات → التصنيفات → الإعلانات مقسمة بالتصنيف
- **تفاصيل الإعلان**: معرض صور + فيديوهات + معلومات + خريطة + أزرار التفاعل
- **المعرض (Gallery)**: فيديوهات بنظام TikTok-style مع infinite scroll
- **التصنيفات**: قائمة تصنيفات + صفحة إعلانات كل تصنيف
- **إضافة إعلان**: نموذج تقديم طلب مع رفع صور/فيديو
- **البحث**: بحث في اسم المتجر والعرض والوصف
- **الدعم + الشركاء + سياسة الخصوصية**

### القسم 5: منطق العمل (Business Logic)
- **فلترة المدن**: 3 أنواع (`all`, `region:اسم`, `مدينة1,مدينة2`)
- **اختيار الموقع**: المستخدم يختار مدينة أو منطقة كاملة
- **الإعلانات**: تعرض فقط النشطة (active=true) والتي start_date <= now و (end_date null أو >= now)
- **الإحصائيات**: views + likes مع حفظ حالة الإعجاب محلياً
- **السحوبات**: تسجيل بالاسم ورقم الجوال + عد تنازلي + إعلان الفائز
- **الإعلانات المنبثقة**: تظهر مرة واحدة لكل مدينة في الجلسة
- **رسالة واتساب تلقائية**: نص محدد عند التواصل

### القسم 6: Edge Functions
- إشعارات القبول والتذكير والإشعارات اليدوية
- تحديث إيميل الأدمن

### القسم 7: ملاحظات تقنية للمبرمج
- resolveImageUrl: إذا كان URL كامل يستخدم كما هو، وإلا يعتبر من الأصول المحلية
- نظام الإشعارات عبر Firebase FCM
- التحديث الإجباري عبر جدول app_settings

## التنفيذ
- ملف Markdown واحد شامل محفوظ في `/mnt/documents/`
- منظم بالعربية مع أكواد بالإنجليزية
