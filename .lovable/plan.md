

## خطة: تحسين المعرض (عداد + عشوائي + مشاهدات + لايكات + تكرار لانهائي)

### التعديلات على `src/pages/GalleryPage.tsx`

1. **إزالة عداد الفيديوهات** (سطر 100-106)

2. **ترتيب عشوائي**: خلط الفيديوهات بـ Fisher-Yates shuffle داخل `useMemo`

3. **تكرار لانهائي (Infinite Loop)**: عند الوصول لآخر فيديو يعود تلقائياً للأول — يتم بمضاعفة القائمة (تكرارها 3 مرات مثلاً) مع استخدام modulo للربط بالفيديو الأصلي، أو بمراقبة scroll position وإعادة التموضع برمجياً عند الوصول للنهاية

4. **تسجيل مشاهدة تلقائي**: عند تغيير `activeIndex`، استدعاء `recordView(adId)` من `useAdStats.ts` — يُحدّث قاعدة البيانات مباشرة

5. **إضافة زر لايك جانبي** (على يمين الشاشة):
   - أيقونة قلب (`Heart`) تتحول أحمر عند الإعجاب
   - عدد اللايكات تحته
   - يستخدم `useAdStats(adId)` للفيديو النشط
   - component داخلي `GalleryInteractions` يتلقى `adId` النشط

6. **عدد المشاهدات**: يظهر بجانب أيقونة عين (`Eye`) تحت زر اللايك

### الملفات المتأثرة
- `src/pages/GalleryPage.tsx` — تعديل شامل (إزالة عداد، shuffle، infinite loop، مشاهدات، لايكات)

- لا حاجة لتعديل قاعدة البيانات
