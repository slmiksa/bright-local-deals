

## خطة إضافة تحديد الموقع على الخريطة في نموذج رفع الإعلان

### ملخص
إضافة خريطة تفاعلية (Google Maps) في نموذج رفع الإعلان، العميل يضغط فقط على الخريطة لتحديد موقعه أو يستخدم زر "موقعي الحالي" — بدون أي حقول نصية للتعبئة. يُحفظ الموقع (إحداثيات) مع الطلب ويظهر في لوحة التحكم كخريطة صغيرة عند فتح تفاصيل الطلب.

### المتطلبات
- **مفتاح Google Maps API** (publishable key) مع تفعيل Maps JavaScript API من Google Cloud Console
- المفتاح سيُخزن في الكود مباشرة كونه مفتاح عام

### خطوات التنفيذ

**1. تثبيت مكتبة `@react-google-maps/api`**

**2. تعديل قاعدة البيانات**
- إضافة عمودين `lat` و `lng` (من نوع double precision، nullable) لجدول `ad_requests`

**3. إنشاء مكون `LocationPicker.tsx`**
- خريطة تفاعلية بارتفاع مناسب (~200px)
- زر "📍 تحديد موقعي الحالي" يستخدم Geolocation API
- النقر على الخريطة يحرك الـ Marker للموقع المختار
- Marker قابل للسحب
- **بدون حقول إدخال نصية** — فقط تفاعل مع الخريطة
- يُرجع `lat` و `lng` فقط

**4. تعديل `AddAdPage.tsx`**
- إضافة state لـ `lat` و `lng`
- دمج مكون LocationPicker بعد حقل المدينة (اختياري - غير إجباري)
- إرسال الإحداثيات مع بيانات الطلب عند الحفظ

**5. تعديل `AdminRequestDetail.tsx`**
- إذا كان الطلب يحتوي على إحداثيات، عرض خريطة صغيرة ثابتة (Static Map أو embedded map) مع Marker على الموقع
- إضافة زر "فتح في خرائط Google" يفتح الموقع في تبويب جديد

### ملاحظة
سأطلب منك إدخال مفتاح Google Maps API قبل البدء بالتنفيذ. احصل عليه من:
**Google Cloud Console → APIs & Services → Credentials → Create API Key**
مع تفعيل **Maps JavaScript API**
