

## خطة: استبدال "المميزة" بـ "المعرض" (نظام استوريز للفيديوهات)

### الفكرة
استبدال تاب "المميزة" في الشريط السفلي بتاب "المعرض" يفتح تجربة فيديو بملء الشاشة (مثل ستوريز سناب شات وريلز إنستقرام) تعرض جميع فيديوهات الإعلانات مع إمكانية التمرير عمودياً بينها.

### التعديلات

#### 1. تعديل `src/components/BottomTabBar.tsx`
- استبدال تاب "المميزة" (Star) بـ "المعرض" مع أيقونة مناسبة (مثل `Clapperboard` أو `Film`)
- تغيير المسار من `/featured` إلى `/gallery`

#### 2. إنشاء صفحة جديدة `src/pages/GalleryPage.tsx`
- صفحة فول سكرين بخلفية سوداء تعرض الفيديوهات عمودياً
- كل فيديو يأخذ كامل الشاشة مع تمرير عمودي (snap scrolling)
- كل فيديو يعرض:
  - **اسم الإعلان** (shopName) في الأسفل
  - **زر "عرض الإعلان"** للانتقال لصفحة تفاصيل الإعلان
  - **زر إغلاق (X)** في الأعلى للخروج والعودة للتطبيق
- الفيديو الظاهر حالياً يعمل تلقائياً (autoplay)، والباقي يتوقف
- إخفاء الشريط السفلي (BottomTabBar) عند فتح المعرض

#### 3. إنشاء hook جديد `src/hooks/useVideoAds.ts`
- يجلب جميع الإعلانات التي تحتوي فيديوهات من قاعدة البيانات
- يُرجع قائمة بالفيديوهات مع بيانات الإعلان (الاسم، الـ id)

#### 4. تعديل `src/App.tsx`
- استبدال route `/featured` بـ `/gallery`
- استيراد `GalleryPage` بدلاً من `FeaturedPage`

#### 5. تعديل `src/components/BottomTabBar.tsx`
- إخفاء الشريط عند مسار `/gallery`

### تجربة المستخدم
```text
┌──────────────────────┐
│  ✕                   │  ← زر إغلاق
│                      │
│                      │
│    [فيديو فول سكرين] │  ← تمرير عمودي بين الفيديوهات
│                      │
│                      │
│  ┌──────────────────┐│
│  │ محل غيوم الساحل  ││  ← اسم الإعلان
│  │ [عرض الإعلان →]  ││  ← زر الانتقال للتفاصيل
│  └──────────────────┘│
└──────────────────────┘
```

### الملفات المتأثرة
- `src/pages/GalleryPage.tsx` — جديد
- `src/hooks/useVideoAds.ts` — جديد
- `src/components/BottomTabBar.tsx` — تعديل (اسم + أيقونة + إخفاء)
- `src/App.tsx` — تعديل (route)
- `src/pages/FeaturedPage.tsx` — يمكن حذفه أو إبقاؤه
