

# إضافة رابط الراعي في نظام السحوبات

## الفكرة
عند إضافة راعي للسحب، يجب أن يكون هناك رابط (URL) يوجّه المستخدم لموقع الراعي أو سناب شاته أو إعلانه. حالياً الراعي يظهر كاسم ولوقو فقط بدون أي تفاعل.

## التغييرات المطلوبة

### 1. قاعدة البيانات
إضافة عمود جديد لجدول `giveaways`:
- `sponsor_url` (text, nullable) — رابط الراعي (موقع، سناب شات، إعلان، إلخ)

### 2. لوحة التحكم (`AdminGiveaways.tsx`)
- إضافة حقل "رابط الراعي" (اختياري) بجانب حقول اسم الراعي ولوقو الراعي
- حفظ الرابط مع باقي بيانات السحب

### 3. واجهة المستخدم (`GiveawaySection.tsx`)
- تحويل قسم "برعاية [اسم]" من نص عادي إلى **زر قابل للضغط** يفتح رابط الراعي في نافذة جديدة
- إذا لم يُحدد رابط، يبقى كنص عادي بدون ضغط

### الملفات المتأثرة
- Migration SQL (إضافة عمود `sponsor_url`)
- `src/components/GiveawaySection.tsx`
- `src/pages/admin/AdminGiveaways.tsx`
