

## خطة: نظام المناطق والمدن مع عرض اسم المدينة على كل إعلان

### الفكرة
تحويل نظام المدن إلى هيكل **منطقة > مدن**. العميل يختار المنطقة ثم يختار مدينة أو "كل مدن المنطقة". عند اختيار "الكل"، يظهر اسم المدينة بخط صغير بجانب كل إعلان. الأدمن يدير المناطق والمدن ويحدد المكان الافتراضي.

### تجربة المستخدم

```text
┌─────────────────────────┐
│  اختر مدينتك            │
│                         │
│  ▼ منطقة الرياض         │
│    ● كل مدن المنطقة     │
│    ○ الرياض              │
│    ○ الخرج               │
│    ○ الدوادمي            │
│                         │
│  ▶ منطقة مكة            │
│  ▶ منطقة الشرقية        │
└─────────────────────────┘
```

عند اختيار "كل مدن المنطقة"، يظهر في TopBar: "منطقة الرياض" وفي كل كارت إعلان يظهر اسم المدينة بخط صغير تحت اسم المتجر.

### خطوات التنفيذ

**1. قاعدة البيانات**
- إنشاء جدول `regions` (`id uuid`, `name text`, `sort_order int`, `is_default boolean`)
- إضافة عمود `region_id` (uuid, nullable, foreign key) في جدول `cities`
- إضافة عمود `is_default` (boolean, default false) في جدول `cities`
- RLS: قراءة عامة، تعديل للأدمن فقط

**2. لوحة التحكم — إدارة المناطق والمدن (`AdminCities.tsx`)**
- إعادة بناء الصفحة لتشمل:
  - قسم إدارة المناطق (إضافة/تعديل/حذف + تحديد الافتراضية)
  - عند إضافة/تعديل مدينة: اختيار المنطقة من قائمة منسدلة
  - عرض المدن مجمّعة تحت مناطقها
  - زر لتحديد المدينة/المنطقة الافتراضية (التي يفتح عليها التطبيق)

**3. تحديث `CityContext.tsx`**
- تخزين نوع الاختيار: `city` (مدينة محددة) أو `region` (كل مدن المنطقة)
- تخزين `region_id` و `region_name` بالإضافة لـ `city`
- عند أول تشغيل: جلب المنطقة/المدينة الافتراضية من قاعدة البيانات

**4. تحديث `useAds.ts`**
- إضافة hook `useRegionsWithCities()` يجلب المناطق مع مدنها
- تعديل `fetchAds` لدعم فلترة بقائمة مدن (عند اختيار "كل مدن المنطقة")
- تمرير اسم المدينة مع كل إعلان (موجود أصلاً في `ad.city`)

**5. تحديث `TopBar.tsx`**
- تغيير Bottom sheet لعرض المناطق كأقسام accordion
- كل منطقة تحتها: خيار "كل مدن المنطقة" + قائمة المدن
- عرض "منطقة [الاسم]" أو اسم المدينة في الهيدر

**6. تحديث `AdCard.tsx` — عرض اسم المدينة**
- إضافة prop `showCity` (اختياري)
- عند `showCity=true`: عرض اسم المدينة بخط صغير تحت اسم المتجر أو بجانبه
- `AdSection` و `Index` يمررون `showCity=true` عندما يكون الاختيار "كل مدن المنطقة"

**7. تحديث `AddAdPage.tsx`**
- تحويل اختيار المدينة إلى: اختيار المنطقة أولاً ثم تظهر مدنها في قائمة ثانية

### الملفات المتأثرة

- `src/pages/admin/AdminCities.tsx` — إعادة بناء كاملة

- `src/components/TopBar.tsx` — عرض المناطق > المدن
- `src/components/AdCard.tsx` — عرض اسم المدينة

- `src/pages/Index.tsx` — تمرير showCity
- `src/pages/AddAdPage.tsx` — اختيار منطقة ثم مدينة
